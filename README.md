# Python Learning Portfolio

This repository contains the exercises, notebooks, and projects completed during my Python learning journey, including the **IT Academy Barcelona** bootcamp and the previous **Foundations** course.

The objective of this repository is to document my progress while learning Python, data analysis, and problem-solving through practical exercises.

### 📂 Fundamentals
Exercises completed during the **Foundations** course before starting the Data Analytics Bootcamp. This folder includes basic Python programming, control structures, functions, collections, file handling, and additional practice notebooks.

Exercises and projects completed during the **IT Academy Data Analytics Bootcamp**. Each sprint focuses on different Python concepts and data analysis techniques, progressively increasing in complexity.

Topics covered include:

- Python fundamentals
- Object-oriented programming
- Functions and modules
- File management
- Exception handling
- Regular expressions
- Web scraping
- APIs
- SQL
- Data analysis with Pandas
- Data visualization with Matplotlib and Seaborn
- Machine Learning fundamentals
